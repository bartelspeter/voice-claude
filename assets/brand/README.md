# Voice Claude brand sources

Exported from the Claude Design project "Voice Claude app logo designs" (identity sheet 3a).

- `mark.svg`: the five-bar mark, ink on transparent with the centre bar in brand blue.
- `mark-ondark.svg`: the same mark in white with the lighter blue for dark grounds.
- `icon.svg`: the mark on the pale ground with the rounded app-icon corners.
- `fonts/Sora[wght].ttf`: the wordmark face (SIL Open Font License, see `fonts/OFL.txt`).

Palette: ink `#1B1D22`, blue `#3E7BD6` (`#5F95E6` on dark), ground `#F4F6FA`.
Wordmark: Sora SemiBold, tracking -0.035em, "Voice" in ink and "Claude" in blue.

Run `python3 assets/brand/render.py` to regenerate every PNG in `assets/` and `store/`
(needs Inkscape and Pillow).
